---
title: "CLI commands"
description: "Reference for the xccode command line."
---

Every command accepts `--help` for its full flag list, for example `xccode run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ xccode run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: Xccode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @xccode/cli
      - run: xccode run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ xccode run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ xccode run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ xccode run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ xccode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ xccode run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ xccode run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ xccode run --auto "Fix the failing test"
```

Create the session archived so scripted or CI runs stay out of session lists and the inbox. The session still exists: `xccode session list` includes it, and you can open it by ID.

```bash
$ xccode run --archived "Review this diff"
```

View all subcommands and flags.

```bash
$ xccode run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ xccode mini
```

Continue the last session.

```bash
$ xccode mini --continue
```

Start with a model and an initial prompt.

```bash
$ xccode mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ xccode mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ xccode mini --help
```

## session

Manages sessions.

```bash
$ xccode session list
```

Limit the list and print JSON.

```bash
$ xccode session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ xccode session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ xccode session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ xccode session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ xccode session import session.json
```

Import into a specific directory.

```bash
$ xccode session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ xccode session --help
```

## auth

Manages AI providers and credentials.

```bash
$ xccode auth list
```

List them as JSON.

```bash
$ xccode auth list --format json
```

Log in to a provider.

```bash
$ xccode auth login anthropic
```

Log in with a specific authentication method.

```bash
$ xccode auth login anthropic --method key
```

Log out of a saved account.

```bash
$ xccode auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ xccode auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ xccode auth export anthropic > credentials.json
$ xccode auth import credentials.json
```

View all subcommands and flags.

```bash
$ xccode auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ xccode mcp list
```

Add a remote server.

```bash
$ xccode mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ xccode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ xccode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ xccode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ xccode mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ xccode mcp logout sentry
```

View all subcommands and flags.

```bash
$ xccode mcp --help
```

## plugin

Manages plugins.

```bash
$ xccode plugin list
```

Include built-in server plugins.

```bash
$ xccode plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ xccode plugin add @example/xccode-tui
```

Check package plugins for updates.

```bash
$ xccode plugin check
```

Update package plugins.

```bash
$ xccode plugin update
```

Remove a plugin from global configuration.

```bash
$ xccode plugin remove @example/xccode-tui
```

View all subcommands and flags.

```bash
$ xccode plugin --help
```

Shows shareable usage statistics.

```bash

```

```bash
$ xccode stats --days 7
```

Show model usage.

```bash
$ xccode stats --models
```

Show cost and token details.

```bash
$ xccode stats --cost
```

Print JSON instead of a report.

```bash
$ xccode stats --json
```

Show only the current project.

```bash
$ xccode stats --project .
```

```bash
$ xccode stats --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ xccode serve
```

Bind to all interfaces on a fixed port.

```bash
$ xccode serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ xccode serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ xccode serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ xccode pair
```

Use an external URL in the links.

```bash
$ xccode pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ xccode pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ xccode pair --remote --yes
```

View all subcommands and flags.

```bash
$ xccode pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ xccode service start
```

Restart it.

```bash
$ xccode service restart
```

Show its status.

```bash
$ xccode service status
```

Stop it.

```bash
$ xccode service stop
```

Read a setting.

```bash
$ xccode service get hostname
```

Set a setting.

```bash
$ xccode service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ xccode service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ xccode service set env XCCODE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ xccode service unset hostname
```

View all subcommands and flags.

```bash
$ xccode service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ xccode reload
```

## api

Makes a request to the running server.

```bash
$ xccode api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ xccode api session.list --param limit=10
```

Send a JSON body.

```bash
$ xccode api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ xccode api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ xccode api --help
```

Starts an Agent Client Protocol server over stdin and stdout for editor integrations. It runs until the client closes the connection.

```bash
$ xccode acp
```

View all subcommands and flags.

```bash
$ xccode acp --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ xccode debug agents
```

List configuration sources.

```bash
$ xccode debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ xccode debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ xccode debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ xccode debug paths
```

Print a single path.

```bash
$ xccode debug paths db
```

View all subcommands and flags.

```bash
$ xccode debug --help
```

## upgrade

Upgrades Xccode to the latest or a specific version. Alias: `update`.

```bash
$ xccode upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ xccode upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ xccode upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls Xccode. Session data, configuration, and
state are not removed.

```bash
$ xccode uninstall
```

Preview what would be removed.

```bash
$ xccode uninstall --dry-run
```

View all subcommands and flags.

```bash
$ xccode uninstall --help
```
