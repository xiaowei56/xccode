---
title: "CLI commands"
description: "Reference for the xiaochuan command line."
---

Every command accepts `--help` for its full flag list, for example `xiaochuan run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ xiaochuan run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: Xiaochuan review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @xiaochuan/cli
      - run: xiaochuan run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ xiaochuan run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ xiaochuan run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ xiaochuan run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ xiaochuan run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ xiaochuan run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ xiaochuan run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ xiaochuan run --auto "Fix the failing test"
```

Create the session archived so scripted or CI runs stay out of session lists and the inbox. The session still exists: `xiaochuan session list` includes it, and you can open it by ID.

```bash
$ xiaochuan run --archived "Review this diff"
```

View all subcommands and flags.

```bash
$ xiaochuan run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ xiaochuan mini
```

Continue the last session.

```bash
$ xiaochuan mini --continue
```

Start with a model and an initial prompt.

```bash
$ xiaochuan mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ xiaochuan mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ xiaochuan mini --help
```

## session

Manages sessions.

```bash
$ xiaochuan session list
```

Limit the list and print JSON.

```bash
$ xiaochuan session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ xiaochuan session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ xiaochuan session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ xiaochuan session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ xiaochuan session import session.json
```

Import into a specific directory.

```bash
$ xiaochuan session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ xiaochuan session --help
```

## auth

Manages AI providers and credentials.

```bash
$ xiaochuan auth list
```

List them as JSON.

```bash
$ xiaochuan auth list --format json
```

Log in to a provider.

```bash
$ xiaochuan auth login anthropic
```

Log in with a specific authentication method.

```bash
$ xiaochuan auth login anthropic --method key
```

Log out of a saved account.

```bash
$ xiaochuan auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ xiaochuan auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ xiaochuan auth export anthropic > credentials.json
$ xiaochuan auth import credentials.json
```

View all subcommands and flags.

```bash
$ xiaochuan auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ xiaochuan mcp list
```

Add a remote server.

```bash
$ xiaochuan mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ xiaochuan mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ xiaochuan mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ xiaochuan mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ xiaochuan mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ xiaochuan mcp logout sentry
```

View all subcommands and flags.

```bash
$ xiaochuan mcp --help
```

## plugin

Manages plugins.

```bash
$ xiaochuan plugin list
```

Include built-in server plugins.

```bash
$ xiaochuan plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ xiaochuan plugin add @example/xiaochuan-tui
```

Check package plugins for updates.

```bash
$ xiaochuan plugin check
```

Update package plugins.

```bash
$ xiaochuan plugin update
```

Remove a plugin from global configuration.

```bash
$ xiaochuan plugin remove @example/xiaochuan-tui
```

View all subcommands and flags.

```bash
$ xiaochuan plugin --help
```




```bash

```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ xiaochuan serve
```

Bind to all interfaces on a fixed port.

```bash
$ xiaochuan serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ xiaochuan serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ xiaochuan serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ xiaochuan pair
```

Use an external URL in the links.

```bash
$ xiaochuan pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ xiaochuan pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ xiaochuan pair --remote --yes
```

View all subcommands and flags.

```bash
$ xiaochuan pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ xiaochuan service start
```

Restart it.

```bash
$ xiaochuan service restart
```

Show its status.

```bash
$ xiaochuan service status
```

Stop it.

```bash
$ xiaochuan service stop
```

Read a setting.

```bash
$ xiaochuan service get hostname
```

Set a setting.

```bash
$ xiaochuan service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ xiaochuan service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ xiaochuan service set env XIAOCHUAN_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ xiaochuan service unset hostname
```

View all subcommands and flags.

```bash
$ xiaochuan service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ xiaochuan reload
```

## api

Makes a request to the running server.

```bash
$ xiaochuan api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ xiaochuan api session.list --param limit=10
```

Send a JSON body.

```bash
$ xiaochuan api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ xiaochuan api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ xiaochuan api --help
```

```bash
$ xiaochuan acp
```

View all subcommands and flags.

```bash
$ xiaochuan acp --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ xiaochuan debug agents
```

List configuration sources.

```bash
$ xiaochuan debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ xiaochuan debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ xiaochuan debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ xiaochuan debug paths
```

Print a single path.

```bash
$ xiaochuan debug paths db
```

View all subcommands and flags.

```bash
$ xiaochuan debug --help
```

## upgrade

Upgrades Xiaochuan to the latest or a specific version. Alias: `update`.

```bash
$ xiaochuan upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ xiaochuan upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ xiaochuan upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls Xiaochuan. Session data, configuration, and
state are not removed.

```bash
$ xiaochuan uninstall
```

Preview what would be removed.

```bash
$ xiaochuan uninstall --dry-run
```

View all subcommands and flags.

```bash
$ xiaochuan uninstall --help
```
