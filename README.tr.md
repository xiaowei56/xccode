### Kurulum

```bash
# YOLO
curl -fsSL https://xiaochuan.ai/v2/install | bash

# Paket yöneticileri
npm i -g @xiaochuan/cli@latest      # veya bun/pnpm/yarn
brew install anomalyco/tap/xiaochuan-v2 # macOS ve Linux (önerilir, her zaman güncel)
brew install xiaochuan              # macOS ve Linux (resmi brew formülü, daha az güncellenir)
sudo pacman -S xiaochuan            # Arch Linux (Stable)
paru -S xiaochuan-beta              # Arch Linux (Latest from AUR)
mise use -g xiaochuan               # Tüm işletim sistemleri
nix run github:xiaowei56/xiaochuan  # Nix
```

> [!TIP]
> Kurulumdan önce 0.1.x'ten eski sürümleri kaldırın.

### Masaüstü Uygulaması (BETA)

Xiaochuan ayrıca masaüstü uygulaması olarak da mevcuttur. [xiaochuan.ai/download](https://xiaochuan.ai/download) adresinden indirebilirsiniz.

| Platform              | İndirme                            |
| --------------------- | ---------------------------------- |
| macOS (Apple Silicon) | `xiaochuan-desktop-mac-arm64.dmg`   |
| macOS (Intel)         | `xiaochuan-desktop-mac-x64.dmg`     |
| Windows               | `xiaochuan-desktop-win-x64.exe`     |
| Linux                 | `.deb`, `.rpm` veya AppImage       |

```bash
# macOS (Homebrew)
brew install --cask xiaochuan-desktop
```

#### Kurulum Dizini (Installation Directory)

Kurulum betiği, Xiaochuan'u `$HOME/.xiaochuan/bin` dizinine kurar.

### Ajanlar

Xiaochuan, `Tab` tuşuyla aralarında geçiş yapabileceğiniz iki yerleşik (built-in) ajan içerir.

- **build** - Varsayılan, geliştirme çalışmaları için tam erişimli ajan
- **plan** - Analiz ve kod keşfi için salt okunur ajan
  - Varsayılan olarak dosya düzenlemelerini reddeder
  - Bash komutlarını çalıştırmadan önce izin ister
  - Tanımadığınız kod tabanlarını keşfetmek veya değişiklikleri planlamak için ideal

Ayrıca, karmaşık aramalar ve çok adımlı görevler için bir **genel** alt ajan bulunmaktadır.
Bu dahili olarak kullanılır ve mesajlarda `@general` ile çağrılabilir.

[Ajanlar](https://xiaochuan.ai/docs/agents) hakkında daha fazla bilgi edinin.
