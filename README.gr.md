### Εγκατάσταση

```bash
# YOLO
curl -fsSL https://xiaochuan.ai/v2/install | bash

# Διαχειριστές πακέτων
npm i -g @xiaochuan/cli@latest      # ή bun/pnpm/yarn
brew install anomalyco/tap/xiaochuan-v2 # macOS και Linux (προτείνεται, πάντα ενημερωμένο)
brew install xiaochuan              # macOS και Linux (επίσημος τύπος brew, λιγότερο συχνές ενημερώσεις)
sudo pacman -S xiaochuan            # Arch Linux (Σταθερό)
paru -S xiaochuan-beta              # Arch Linux (Τελευταία έκδοση από AUR)
mise use -g xiaochuan               # Οποιοδήποτε λειτουργικό σύστημα
nix run github:xiaowei56/xiaochuan  # Nix
```

> [!TIP]
> Αφαίρεσε παλαιότερες εκδόσεις από τη 0.1.x πριν από την εγκατάσταση.

### Εφαρμογή Desktop (BETA)

Το Xiaochuan είναι επίσης διαθέσιμο ως εφαρμογή. Κατέβασε το από το [xiaochuan.ai/download](https://xiaochuan.ai/download).

| Πλατφόρμα             | Λήψη                               |
| --------------------- | ---------------------------------- |
| macOS (Apple Silicon) | `xiaochuan-desktop-mac-arm64.dmg`   |
| macOS (Intel)         | `xiaochuan-desktop-mac-x64.dmg`     |
| Windows               | `xiaochuan-desktop-win-x64.exe`     |
| Linux                 | `.deb`, `.rpm`, ή AppImage         |

```bash
# macOS (Homebrew)
brew install --cask xiaochuan-desktop
```

#### Κατάλογος Εγκατάστασης

Το script εγκατάστασης εγκαθιστά το Xiaochuan στο `$HOME/.xiaochuan/bin`.

### Πράκτορες

Το Xiaochuan περιλαμβάνει δύο ενσωματωμένους πράκτορες μεταξύ των οποίων μπορείτε να εναλλάσσεστε με το πλήκτρο `Tab`.

- **build** - Προεπιλεγμένος πράκτορας με πλήρη πρόσβαση για εργασία πάνω σε κώδικα
- **plan** - Πράκτορας μόνο ανάγνωσης για ανάλυση και εξερεύνηση κώδικα
  - Αρνείται την επεξεργασία αρχείων από προεπιλογή
  - Ζητά άδεια πριν εκτελέσει εντολές bash
  - Ιδανικός για εξερεύνηση άγνωστων αρχείων πηγαίου κώδικα ή σχεδιασμό αλλαγών

Περιλαμβάνεται επίσης ένας **general** υποπράκτορας για σύνθετες αναζητήσεις και πολυβηματικές διεργασίες.
Χρησιμοποιείται εσωτερικά και μπορεί να κληθεί χρησιμοποιώντας `@general` στα μηνύματα.

Μάθετε περισσότερα για τους [πράκτορες](https://xiaochuan.ai/docs/agents).
